# 英语复习站：从空仓库开始使用

这套文件适用于 GitHub Pages。只需要上传本文件夹中的 **6 个 Markdown 文件**，再开启一次 Pages。页面包含分类切换、英文／中文／年份搜索、年份筛选、标签筛选、排序和遮住释义的背诵模式。

使用 GitHub 提供的 github.io 地址，公开仓库即可免费托管。不用购买服务器、域名或搜索服务，也不用在电脑上安装 Quartz、Node.js、Ruby 等环境。发布时使用 GitHub Pages 自带的 Markdown 转网页功能（Jekyll）；你只需在 GitHub 网页里上传和编辑文件。

## 一、应该上传哪些文件

| 文件 | 作用 | 后续是否经常修改 |
| --- | --- | --- |
| index.md | 网站首页、分类切换、自动收集词库、搜索与筛选 | 通常不用修改 |
| 01_真题词汇.md | 714 条归并后的词汇与辨析记录 | 新增真题单词时修改 |
| 02_真题短语.md | 339 条归并后的短语、搭配与结构记录 | 新增短语时修改 |
| 03_待巩固词句.md | 动态词库中的全部 49 条个人记录 | 日常重点维护 |
| 04_长难句解析.md | 3 条已分层解析的真题长难句 | 新增句子分析时修改 |
| README.md | 本使用指南 | 通常不用修改 |

合计 **1,105 条复习记录**。这不是 1,105 个互不重复的单词：词汇辨析可能把一组词放在一条中；同一表达也可能同时出现在真题分类和待巩固分类，方便分别复习。

相同分类中的同一词目已归并；不同年份的语境义、原文片段和出处保留在展开内容中。没有根据猜测给个人词库补充年份。

## 二、第一次部署：照着操作

### 第 1 步：下载并解压

下载提供的 ZIP 压缩包，在电脑上解压，进入“英语复习站_GitHub_Pages”文件夹，确认能看到上表中的 6 个 .md 文件。

**上传的是解压后的 6 个文件，不是 ZIP 压缩包。** 这 6 个文件应在仓库最外层；不要把整个外层文件夹作为子目录上传。

### 第 2 步：打开你新建的仓库

先确认仓库是 **Public（公开）**。GitHub Free 的 Pages 使用公开仓库；网站和其中的学习材料也会公开可访问。

- 如果仓库完全为空，在页面的 Quick setup 区域找到 **uploading an existing file**，点击它。
- 如果仓库已经有 README 等文件，点击 **Add file → Upload files**。

把上表中的 6 个 .md 文件一起拖进去。上传后，在页面下方的提交说明中写“初始化英语复习站”，点击 **Commit changes**。个人空仓库通常可直接提交到默认分支；如果界面让你选择分支，选择你之后用于 Pages 发布的那个分支。

提交后，回到仓库首页，应该直接看到 index.md、01_真题词汇.md 等文件名，而不是只看到一个包住它们的文件夹。

### 第 3 步：开启 GitHub Pages

在仓库中依次点击：

1. **Settings**。
2. 左侧 **Pages**。
3. 在 **Build and deployment** 区域，将 **Source** 设为 **Deploy from a branch**。
4. 在 **Branch** 下选择包含这 6 个文件的分支，通常是 **main**。如果你的默认分支叫 master，就选择 master。
5. 文件夹选择 **/ (root)**。
6. 点击 **Save**。

本方案不需要选择主题、不需要手写 GitHub Actions 工作流，也不需要额外的 _config.yml。

### 第 4 步：等发布完成，再打开网址

发布通常需要几分钟；GitHub 官方说明更新可能需要最多约 10 分钟。可以在仓库 **Actions** 中查看 Pages 的部署是否成功。

完成后回到 **Settings → Pages**，点击页面显示的 **Visit site**。以这里给出的地址为准，不需要自己猜网址。

一般情况下，普通仓库的地址形如：

`https://你的GitHub用户名.github.io/仓库名/`

如果仓库名称恰好是“你的GitHub用户名.github.io”，地址则形如：

`https://你的GitHub用户名.github.io/`

**进入 Pages 网址使用网页。** 在仓库里点击 index.md，只是在看 GitHub 的文件预览，不是实际网站；文件预览不会运行搜索和分类按钮。

### 第 5 步：做一次使用检查

1. 首页应显示 1,105 条记录，4 个分类的数量应分别为 714、339、49、3。
2. 搜索 `claim`，应找到相关词汇或表达。
3. 搜索 `取决于`，应找到对应的英文词句。
4. 搜索 `2019 compensation`，应找到相关词条；展开后可见 2019 年薪酬与 2021 年赔偿的语境区别。
5. 切到“待巩固词句”，应看到 49 条个人学习记录。
6. 切到“长难句解析”，展开 `In a move that …`，可见 have + 宾语 + 形容词的分析。
7. 勾选“遮住释义，试着回忆”，中文概览会隐藏；点击“显示释义与解析”检查答案。

## 三、怎么搜索和筛选

| 操作 | 示例 | 结果含义 |
| --- | --- | --- |
| 搜索英文 | claim | 查找英文词目、原文词形、搭配和解析中含该文本的条目；不区分大小写 |
| 搜索中文 | 主张 | 查找中文释义、备注或解析中含该文本的条目 |
| 搜索年份 | 2010 | 显示明确标注含该年份的条目 |
| 组合搜索 | 2019 compensation | 同时满足年份和关键词条件；空格分开的关键词按“并且”处理 |
| 分类切换 | 真题短语 | 只显示这一分类，同时保留当前搜索和筛选条件 |
| 年份筛选 | 2013 年 | 只显示元数据中明确标注 2013 的记录 |
| 未标年份 | 年份未标注 | 查看尚未填写年份的个人记录或辨析补充 |
| 标签筛选 | 熟词僻义 | 查看有这一标签的条目 |
| 排序 | 英文 A—Z | 按词目排序；另支持原稿顺序和年份从新到旧 |
| 重置筛选 | 点击右侧按钮 | 恢复全部分类、全部年份、全部标签，并清空关键词 |

当前视图会记录在浏览器地址中。把带有搜索条件的网址复制到另一台设备，可直接打开相同分类和筛选；材料本身以仓库最近成功发布的版本为准。

手机上方的分类栏可以左右滑动，以切换到“待巩固词句”和“长难句解析”等分类；正文自动改为单列。

同一词条可能有多个年份和多个词义。年份筛选表示“这个词条包含该年份的明确出处”；展开后仍保留其他年份的语境，便于对照，不要把一条里的所有词义都当成该年考过。

搜索面向现有笔记，不扫描原始真题 PDF，不提供拼写纠错或词根自动联想；例如输入 claim 不自动等同于 criticism。原归纳列出的词形保留在正文中，可以被检索。

快捷键：**Ctrl + K**（Mac 为 Command + K）把光标移到搜索框。

## 四、以后怎么新增一个词或短语

最方便的方法：**修改对应分类的 Markdown 文件，在末尾追加一个词条。** 不用改 index.md，也不用重新整理索引。

1. 在 GitHub 仓库中，点击对应的 .md 文件。
2. 点击铅笔图标 **Edit this file**。
3. 把新词条追加到文件末尾。
4. 点击 **Commit changes**，提交到 Pages 发布的分支。
5. 等自动发布完成，再刷新资料站；必要时按 Ctrl + F5 强制刷新。

例如，你在阅读中对 abuzz 不熟，可以往 **03_待巩固词句.md** 末尾加入：

```markdown
## abuzz：adj. 议论纷纷的；充满嘈杂声的

- 年份：2010
- 标签：形容词、易错词句

### 个人学习记录

- 出处：2010 英语一阅读A·Text 2，PDF第6页。
- 原文片段：has intellectual-property lawyers abuzz
- 用法：have + 宾语 + 形容词，使某人／某物处于某种状态。
- 掌握度：1
- 错误类型：没识别出形容词作宾语补足语。
- 备注：这里的 has 不是完成时助动词，后面也不是过去分词。
```

其中只有两个排版规则需要固定：

- **每条记录以二级标题 `## 英文：中文释义` 开始。** 这里用中文冒号“：”分开词目与释义。
- 标题后保留“年份”和“标签”这两个项目；同一记录内部的分段用三级标题 `###`，不会被误当成新词条。

年份不知道就写 **未标注**；多个年份写“2010、2013、2018”。标签可自行增加，用顿号“、”分隔，网页会自动收集。

同一词出现新词义时，可以把新语境追加到原词条下的 `### 2022 · 新语境` 等分段中，同时把有据可查的年份补到上方“年份”一行。不要只在正文提及年份却忘记修改元数据，否则年份下拉筛选不会把它算进去。

## 五、以后怎么新增长难句

在 **04_长难句解析.md** 末尾追加如下结构；把占位内容替换成真实内容：

```markdown
## 句子开头或简短名称：本句的核心语法结构

- 年份：未标注
- 标签：长难句、定语从句

### 原句

> 这里粘贴完整英文原句。

### 出处

填写年份、阅读篇目或翻译题号、PDF 页码；未知部分如实写未标注。

### 主干

先写主语、谓语和宾语／表语。

### 分层理解

1. 解释第一处修饰或从句。
2. 解释第二处结构及指代。

### 参考译文

填写结合上下文的中文译文。

### 易错点

- 填写容易误判的词义、关系或指代。
```

## 六、想按年份再拆成更多 Markdown 文件，可以吗

可以。现有 4 份是为了先用起来；以后也能拆成“2022_真题词汇.md”“2023_待巩固.md”等多个文件。

每个新词库文件顶部必须保留这样的元数据：

```yaml
---
layout: null
title: 我的补充词库
study_data: true
study_category: review
---
```

`study_category` 只使用下面 4 个值之一：

| 值 | 网页分类 |
| --- | --- |
| vocabulary | 真题词汇 |
| phrase | 真题短语 |
| review | 待巩固词句 |
| sentence | 长难句解析 |

元数据之后正常写一级标题 `# 我的补充词库`，再按“二级标题＝一条记录”的格式添加内容。首页会自动收集所有 `study_data: true` 的页面。为便于直接上传，建议继续放在仓库最外层，文件名不以 `_` 开头。

不要同时保留同一词库的两份完全相同的副本，避免显示两遍。README 没有 `study_data: true`，因此指南里的示例不会混入复习结果。

## 七、同步和维护的实际方式

- 手机、电脑和平板打开同一个 Pages 地址，都能读到最近一次成功发布的内容。
- 内容修改在 GitHub 仓库里提交；页面本身不承担在线写回。标签、备注和掌握度也是修改 Markdown 后再发布。
- 页面里的遮住释义和筛选是阅读操作，不会改写词库；复制当前网址可带走这些查看条件。
- 同一词在“真题词汇”和“待巩固词句”两处保留是有意的：前者管理语境与来源，后者管理自己的薄弱点。改真题释义时，如个人记录也涉及该释义，需要同时核对。

## 八、没有显示或没有更新时，检查什么

| 现象 | 检查与处理 |
| --- | --- |
| Pages 的 Branch 没有可选分支 | 先完成上传并 Commit，空仓库还没有实际分支 |
| 网页 404 | 回 Settings → Pages，确认 Source、发布分支、/ (root) 正确，再用 Visit site 提供的网址 |
| 打开后是 Markdown 源码或仓库文件预览 | 访问 Pages 地址；仓库文件页面不会运行网站按钮 |
| 首页只有界面，词条数量为 0 | 确认其他 4 份词库一起上传；顶部 `study_data: true` 和 `study_category` 没被删改 |
| index.md 没有变成网站 | 不要新建 `.nojekyll`；该文件会关闭本方案依赖的 Markdown 和模板处理。如果已有它，需要删除后提交 |
| 首页与预期不同 | 检查是否存在额外 index.html；避免它与这份 index.md 同时争用首页 |
| Commit 后还是旧内容 | 查看 Actions 的 Pages 部署状态；成功后刷新或强制刷新。官方说明发布可能需要约 10 分钟 |
| 年份筛选找不到新词 | 记录开头的“年份”一行要写真实四位数年份，而不只是在备注里写 |
| 点击分类后结果为空 | 当前关键词、年份或标签可能与该分类不相符；点击“重置筛选”检查 |
| 新增的一段被拆成多条 | 一条记录内部使用 `###`，只有新记录才使用 `##` |

## 九、资料口径和本次处理

来源为原先的 **2010-2015_考研英语一_单词与短语归纳.md**、**2016-2021_考研英语一_单词与短语归纳.md**，以及你提供的 **动态词库.md**。本次以重排、归并和站点制作处理为主，没有重新把全部原卷逐字统计一遍，也没有借助答案册判定完形选项答案。

原先两份归纳中的逐年重点词、短语、完形候选词、熟词多义、辨析补充和语境例句均已迁入；同分类的相同词目归并为一条，保留各来源说明。词义概览优先展示常用义，具体真题义请展开查看。不能把概览中的每个义项都视作每个列出年份的考查词义。

2010—2015 原归纳里的正文频次只适用于那 6 年原定范围：完形正文、阅读 A 正文、新题型全文和备选句段、翻译全文；不含题干、阅读选项、作文指令等。常见复数、时态和分词按原稿列明的词形组合并，派生词不整组混算。2016—2021 的“跨年复现”保留原稿确认的年份，不据此编造总词频。本站不提供未经重新核验的 12 年统一频次排行榜。

PDF 页码均沿用原归纳中的阅读器页码。2020 年原材料没有封面，页码口径与其他年份不同，不能直接按同一个偏移量换算试卷印刷页码。

原稿的 **Vicwardian prose、the commons of the mind、betray any common humanity** 仍保留待核验、暂定译法或语境判断标记；**access risk / assess risk** 保留原 PDF 疑似笔误的说明。它们都可以通过关键词搜索。

个人动态词库的 49 条记录保留了类型、原稿掌握度、错误类型、备注。原稿“高／中／低”改称“原稿优先级”，明确它是主观标记，不是本次语料统计。对 `be a function of...`、`beyond that of...`、`business-method claim` 等含义作了校订，原释义与理由留在展开内容中，原上传文件不受影响。

3 条长难句来自现有原卷文字：2010 阅读 Text 2 的专利句；2013 翻译第46、47题。解析分别覆盖 have + 宾语 + 形容词、形式主语／指代、however 让步从句等结构。
